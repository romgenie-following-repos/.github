# romgenie-following-repos

This organization is an archive of followed and forked AI-agent projects, kept for reference. All four repositories are archived (read-only) and are not maintained here. These projects are the work of their upstream authors, and credit belongs to them; each repository keeps its upstream README and any upstream license file.

| Repository | What it is | Upstream |
| --- | --- | --- |
| [AgentLaboratory-archived](https://github.com/romgenie-following-repos/AgentLaboratory-archived) | Agent Laboratory is an end-to-end autonomous research workflow meant to assist you as the human researcher toward implementing your research ideas | [SamuelSchmidgall/AgentLaboratory](https://github.com/SamuelSchmidgall/AgentLaboratory) |
| [open_deep_research](https://github.com/romgenie-following-repos/open_deep_research) | A web research assistant that generates reports on a topic, with a customizable model, prompts and search API | [langchain-ai/open_deep_research](https://github.com/langchain-ai/open_deep_research) |
| [openai-realtime-agents](https://github.com/romgenie-following-repos/openai-realtime-agents) | A Next.js demo of agent handoffs and multi-agent patterns built on the OpenAI Realtime API | [openai/openai-realtime-agents](https://github.com/openai/openai-realtime-agents) |
| [freysa](https://github.com/romgenie-following-repos/freysa) | Code and a README describing the Freysa AI-safety challenge, in which players try to persuade an AI agent to release a treasury | Original source: [0xfreysa/agent](https://github.com/0xfreysa/agent) |

Because the repositories are archived, their descriptions, topics and files cannot be changed here. For current versions of these projects, follow the upstream links above.
